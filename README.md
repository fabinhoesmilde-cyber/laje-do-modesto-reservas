# Sistema de Reservas - Laje do Modesto

Sistema completo para gerenciamento de reservas da Laje do Modesto.

## Objetivo

O sistema tem como objetivo automatizar o gerenciamento de reservas, pagamentos, adicionais e controle de agenda da Laje do Modesto.

---

## Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Cadastro de clientes
- Sistema de reservas
- Controle de pagamentos
- Cupons de desconto
- Adicionais da reserva
- Datas bloqueadas
- Painel administrativo

---
