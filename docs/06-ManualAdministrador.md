# Manual do Administrador

# Laje do Modesto Reservas

## Objetivo

Este manual descreve todas as funcionalidades disponíveis para o administrador do sistema **Laje do Modesto Reservas**.

O administrador é o responsável pelo gerenciamento completo das reservas e pela administração do funcionamento da plataforma.

---

# Acesso ao Sistema

O acesso ao painel administrativo é realizado através da página de login.

O administrador deverá informar:

* Usuário
* Senha

Após a autenticação, o sistema gerará um Token de acesso que permitirá utilizar as funcionalidades administrativas.

---

# Dashboard

Ao acessar o painel, o administrador visualizará um resumo das principais informações do sistema.

Indicadores disponíveis:

* Total de reservas.
* Reservas confirmadas.
* Alterações pendentes.
* Cancelamentos pendentes.
* Reservas do dia.

---

# Pesquisa de Reservas

O painel permite pesquisar reservas utilizando:

* Código da reserva.
* Nome do cliente.
* CPF.
* Data da reserva.

---

# Gerenciamento de Reservas

O administrador poderá:

* Criar reservas.
* Editar reservas.
* Consultar reservas.
* Cancelar reservas.
* Aprovar alterações solicitadas pelos clientes.
* Rejeitar alterações.
* Aprovar cancelamentos.
* Rejeitar cancelamentos.

---

# Bloqueio de Datas

O administrador poderá bloquear datas para impedir novas reservas.

Exemplos:

* Manutenção.
* Feriados.
* Eventos particulares.
* Reformas.

---

# Cupons

O administrador poderá:

* Criar cupons.
* Editar cupons.
* Ativar ou desativar cupons.
* Definir validade.
* Definir percentual de desconto.

---

# Adicionais

O administrador poderá cadastrar e gerenciar serviços adicionais oferecidos junto à reserva.

---

# Pagamentos

O administrador poderá consultar o status dos pagamentos realizados pelos clientes.

---

# Logout

Ao finalizar o uso do sistema, o administrador deverá utilizar a opção **Sair**, encerrando a sessão com segurança.

---

# Boas Práticas

* Não compartilhar usuário e senha.
* Sempre realizar logout ao finalizar o uso.
* Conferir os dados antes de aprovar alterações ou cancelamentos.
* Manter os cupons e adicionais atualizados.
